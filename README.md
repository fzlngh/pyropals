# PYROPALS
 Pyropals adalah sebuah game pixel art bebasis adventure dimana seorang player yang berusaha menyelamatkan hewan pada kebakaran hutan yang membahayakan nyawanya

# TUTORIAL
 1. gunakan A untuk mundur, D untuk maju, space untuk loncat dan E untuk mengeluarkan cage
 2. selamatkan rusa dan jangan sampai tertabrak oleh rusanya maka kalian akan mati
 3. jika kalian terlalu dekat maka kalian akan mati
